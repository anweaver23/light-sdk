# Scripture index source

`index.json` lists the volumes, books, abbreviations and chapter counts. It is generated with the verse
text from [bcbooks/scriptures-json](https://github.com/bcbooks/scriptures-json) (public domain / CC0); see
`src/test/resources/scripture-text/SOURCE.md` for the commit and how to regenerate. No verse text is
bundled: the app imports it from the Church's downloads.
