# KJV italics: source

Everything in this directory is generated by `tool/scripts/build_italics_assets.py`.

- **eBible.org, "King James (Authorized) Version", ID `eng-kjv2006`**, USFM edition:
  <https://ebible.org/Scriptures/eng-kjv2006_usfm.zip>
  (details: <https://ebible.org/find/details.php?id=eng-kjv2006>). Downloaded 2026-11-02,
  2466541 bytes, SHA-256 `ce1f526c64c2376f407308c2c23cb2d2fb58efaf5296327d2d8e408c3700650d`.
  This is the same source as the Strong's tags (see `../strongs/SOURCE.md`), re-downloaded.
- **License: Public Domain** (as stated on the eBible.org details page).

The source marks the words the KJV translators supplied, which print in italics, with `\add`.
Only which of OUR words are italic is kept: inclusive word-index runs per verse, re-anchored onto our
verse text (bcbooks/scriptures-json, see `../scriptures/SOURCE.md`) with the Strong's alignment. No
text from this source is bundled. The 2026-11-02 build placed all 26,998 italic source words.

Regenerate with:

    python3 -I tool/scripts/build_italics_assets.py <unzipped usfm dir> tool/src/main/assets/scriptures tool/src/main/assets/italics
