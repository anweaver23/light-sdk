# Strong's original-language data: sources

Everything in this directory is generated by `tool/scripts/build_strongs_assets.py`.

## 1. Strong's-tagged KJV (word tags in `ot/` and `nt/`)

- **eBible.org, "King James (Authorized) Version", ID `eng-kjv2006`**, USFM edition:
  <https://ebible.org/Scriptures/eng-kjv2006_usfm.zip>
  (details: <https://ebible.org/find/details.php?id=eng-kjv2006>). Downloaded 2026-10-14, server
  `Last-Modified: Tue, 13 Oct 2026 03:50:15 GMT`, 2,462,428 bytes,
  SHA-256 `77bbe9c78f4f588b1465e49ddad986293a09e7f4b140abe7248232c8c5ae2a5b`.
- **License: Public Domain** (as stated on the eBible.org details page: "The King James Version ...
  with Strong's numbers added. Public Domain"; outside the UK the KJV text is public domain).
- Provenance: "courtesy of the Crosswire Bible Society and eBible.org". The tagging is CrossWire's
  KJV2003/KJV2006 project: OT Strong's numbers from The Bible Foundation, NT from the KJV2003 Project,
  synchronized to Dr. Maurice Robinson's Textus Receptus.
- We do NOT use CrossWire's own SWORD `KJV` module directly: its `.conf` says
  `DistributionLicense=GPL` (its About text grants a general license "for any purpose", but the GPL
  label is ambiguous). eBible.org redistributes the same tagging as public domain.

Only the Strong's numbers are kept, re-anchored onto OUR verse text (bcbooks/scriptures-json, see
`../scriptures/SOURCE.md`) by word index. No text from this source is bundled.

## 2. Strong's dictionaries (`dict/H`, `dict/G`)

From **openscriptures/strongs**, <https://github.com/openscriptures/strongs>, commit
`0acd2f251c2d35ff8db2dece4e0593979d3ac223` (2021-07-15), using the XML files only:

- Hebrew: `hebrew/StrongHebrewG.xml`, James Strong, *A Concise Dictionary of the Words in the Hebrew
  Bible* (1894). XML by David Troidl and David Instone-Brewer (2LetterLookup.com).
  The file's header declares `<rights>Public Domain</rights>`.
- Greek: `greek/StrongsGreekDictionaryXML_1.4/strongsgreek.xml`, James Strong, *Dictionary of Greek
  Words* (1890), XML v1.4 (2007-09-14) by Ulrik Petersen. The file's prologue reads
  "Public Domain -- Copy Freely".

**License: Public Domain.** Note: the same repo's *JSON* files (`strongs-*-dictionary.js`) are marked
"Copyright 2010, Open Scriptures. CC-BY-SA". We deliberately build from the public-domain XML instead,
so no ShareAlike obligation applies. Only Strong's own fields are kept: lemma, transliteration,
pronunciation, definition, derivation and KJV usage. The Hebrew XML also carries BDB-style outline
glosses (`<list>`), TWOT numbers (`gloss`) and LXX equivalents (`<foreign>`); these are dropped.

Edits: whitespace collapsed, a trailing ";" or "," removed, cross-references rendered as "H7218" /
"G3004", the Greek KJV-usage lead-in ":--" removed, loose Greek "Compare G2799." notes appended to
the derivation, and all strings Unicode NFC-normalized.

## Format

- `ot/<book>.json`, `nt/<book>.json`: `{"tok": <crc32>, "c": [[[w, n, w, n, ...], ...verses], ...chapters]}`.
  `w` is the word index from `core/Words.spans` on our verse text; `n` is the Strong's number without
  its prefix (H for `ot`, G for `nt`). A word with several numbers repeats its index; a multi-word
  rendering puts the same number on each of its words. `tok` is a CRC-32 over the book's tokens, which
  a unit test recomputes in Kotlin to prove both tokenizers agree.
- `dict/<H|G>/<n / 100>.json`: `{"7225": {"l": lemma, "x": transliteration, "p": pronunciation,
  "d": definition, "r": derivation, "k": KJV usage}, ...}`, 100 numbers per shard.

## Alignment result (2026-10-14)

31,102 verses; all 361,133 tagged source words placed (100%), no verse numbering differences, no
unresolved differences. Our text differs from the tagged source only in: curly vs straight
apostrophes (1,763 words), æ vs ae in Greek names (28), small caps (13, e.g. "Lord" vs "LORD"),
modernized spellings (roughly 330 words, e.g. enquire/inquire, vail/veil, jubile/jubilee, stedfast/steadfast;
the full list is `VARIANTS` in the script), and "can not" / "cannot"-style joins, where our single word
takes both numbers.

## Regenerate

Each download goes in its own new, empty directory outside the repo; run Python isolated (`-I`).

    curl -L -o /tmp/ebible/usfm.zip https://ebible.org/Scriptures/eng-kjv2006_usfm.zip
    unzip /tmp/ebible/usfm.zip -d /tmp/ebible/u
    curl -L -o /tmp/os/os.zip https://codeload.github.com/openscriptures/strongs/zip/0acd2f251c2d35ff8db2dece4e0593979d3ac223
    unzip /tmp/os/os.zip -d /tmp/os
    rm -rf tool/src/main/assets/strongs/{ot,nt,dict}
    python3 -I tool/scripts/build_strongs_assets.py /tmp/ebible/u \
        /tmp/os/strongs-*/hebrew/StrongHebrewG.xml \
        /tmp/os/strongs-*/greek/StrongsGreekDictionaryXML_1.4/strongsgreek.xml \
        tool/src/main/assets/scriptures tool/src/main/assets/strongs

The script prints coverage, the differences between the two texts and the worst verses. eBible.org
updates its files in place, so re-check the report (and the tests) after a fresh download.
`python3 -I tool/scripts/build_strongs_assets.py --selfcheck` checks the tokenizer port alone.
